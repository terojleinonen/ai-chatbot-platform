# AI Chatbot Platform (Java + React + AI Microservice + Widget)

This is a template repo for a multi-tenant AI Chatbot platform using:

- `backend/` — Spring Boot main backend with WebSocket chat and REST APIs
- `ai-microservice/` — Spring Boot AI engine using TF-IDF for FAQ-style answers
- `frontend-admin/` — React + Vite admin panel for tenants and FAQs
- `widget/` — Embeddable JavaScript chat widget

See inline comments in each module for setup instructions.
